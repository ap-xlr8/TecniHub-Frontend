# Seguridad

Reporta problemas de forma privada al responsable del proyecto. No publiques credenciales, tokens, datos de usuarios ni pasos que expongan sistemas reales. Incluye impacto, condiciones reproducibles, versiones y mitigación sugerida. Registra la severidad y el estado de corrección sin incluir secretos en evidencia.

Los controles de GitHub (Secret Scanning, Push Protection y CodeQL) dependen de la visibilidad y el plan y requieren habilitación en el repositorio remoto. Este workspace no está conectado a un remoto.
