# Responsabilidades compartidas

Las cuatro funciones académicas son roles organizativos, no cuentas simuladas: líder técnico define arquitectura y decisiones; backend mantiene API y contratos; frontend mantiene Angular/PWA; QA/DevSecOps mantiene controles y evidencia. Hay una persona real que asume las funciones según la tarea. Backend y frontend coordinan el contrato OpenAPI; QA conserva resultados verificables.
