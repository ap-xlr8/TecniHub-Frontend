# Gobernanza Git

El repositorio local inicia en `main` sin commits ni remoto. Flujo documentado: HU aprobada → `sprint/nombre-sprint` → `developer` → `release/vX.Y.Z` → `main`. No crees una rama de funcionalidad no aprobada. Usa PR y plantilla para conservar trazabilidad; la persona actual documenta auto-revisión y checks sin fingir aprobaciones independientes.

Branch protection, rulesets y checks obligatorios requieren remoto y configuración explícita en GitHub. No se aplicaron reglas remotas.
